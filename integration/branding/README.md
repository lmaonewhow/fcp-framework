# 智慧云校品牌覆盖层

产品面向用户的名称为“智慧云校”。此层只在一次性原生组装目录应用，不修改锁定上游仓库或用户工作目录。`manifest.json` 逐文件绑定兼容补丁后的前像、后像、完整补丁摘要和上游提交；先验证三个项目，再开始写入，漂移即停止。上游许可证、源码版权、Maven/Java 包名、JAR 名、API、权限字符串、浏览器会话键和数据库身份保持兼容。

覆盖双端网页标题、登录与侧栏名称、logo/favicon、默认头像、首页、通知中的上游宣传外链、教师端默认水印和原生启动横幅。去掉演示用户名/密码预填值，教师端注册入口遵循已有注册开关；不改变原生验证码、加密登录、认证与权限实现。首页不展示假统计。原作者许可证和版权完整保存在双端同源 `third-party-notices.txt`，登录/页脚提供“开源许可”入口，发布目录继续携带原许可证文件。

管理端代码生成下载名的修补独立后置，兼容 dev 的完整兼容后像及 PR12 的完整生成器后像。不能提前修改该页而绕过生成器的前像检查。生成模板逻辑由生成器模块负责，本层只处理品牌名称与包名示例。

菜单清理见 V009 和 `docs/MIGRATIONS.md`。新空库安装移除精确匹配的 14 个上游网站/测试菜单与引用。修改过的菜单、自定义子树、账号、组织、角色、测试表和业务记录保留。既有库不能通过普通 DDL 迁移工具自动清理，须按文档独立审查并备份。测试夹具不属于产品菜单，继续用于真实验收。

`tools/ci_branding.py` 使用隔离原生 CI 的真实 MySQL、原生登录和双端 Vue 产物，检查登录页、标题、favicon、默认密码、服务端菜单树、刷新、管理端首页及 Back/Forward。截图仅在无凭证的登录页或登录完成后采集。未跑完整 CI 时不能把本地组装、单测或前端构建称为原生验收。
