# P042 教育页面生成与快速调整

`education-p042-v1` 只支持仓库锁定的 P042 SQL/model/catalog。基础资料和名册是两个独立模块；它不是原生 `gen_table` 单表 CRUD 的教育业务开关。生成器先核验完整 SQL，再把 SQL 的类型、长度、可空性与已经审查的字段、接口和操作规则相交，产出完整 Vue 页面、schema、实际 API 请求函数及 provenance。

现有基础资料和名册路由 `index.vue` 只导入各自 `generated/Workspace.vue`。旧手工 Workspace 的布局已明确迁入 `core/src/main/resources/education-generator/templates/`，不是将旧文件冒充生成文件登记。生成页面实际按 schema 显示列、详情字段、表单字段、长度和许可操作。首次快照及之后的候选均由同一个 Java renderer 产生，不执行开发工作区中的脚本。

手工扩展位于 `src/fcp/education/customization.ts`，可快速调整标签、列宽和表单顺序。这些调整只重排或显示已经获准的字段，不能扩大字段、操作或学校授权。此文件及 `useWorkspace`、`useRoster`、transport、响应投影和无损标量代码都不属于生成输出清单。需要新的写入或人员字段时必须先审查业务规则及后端，不应靠修改显示扩展开放。ID 和版本保持字符串，UTC 微秒和业务 DATE 不经浏览器日期转换。

原生生成器的“教育 SQL 生成”入口会显示锁定来源摘要、规则版本和每个模块的表范围。选择模块并预览后仍须明确确认应用，支持历史与撤销。它不执行 SQL、不部署生产、不把学校租户权限转成角色名称判断。现阶段仅开放已实现的学校/组织/班级受限新建与名称 CAS；学期及关系名册只读，人员展示仍为 PENDING，删除、状态变更和身份绑定都未开放。

新 clone 首次应用时，若生成文件与真正候选逐字节一致且尚无基线和归属，会显示“登记已生成文件，不改源码”。确认后只建立后续三方比较所需的基线。请先登记再快速调整；提前手改且没有基线会冲突，不会强行接管。之后生成未变会保留手改，双边变更整批拒绝。撤销登记不删除原有文件；登记之后再手改仍会阻止撤销。64 KiB 截断预览会明确标为不完整，不能当作已审阅全文。

组件回归使用真实 Vue/ElementPlus 和明确的 HTTP/身份替身，覆盖生成 schema 对实际 DOM 与请求的影响，以及 UNKNOWN 回执、取消、身份变化和晚返回。首次迁移只更新了两处组件测试的 Workspace 导入，保留原有断言和全部 data-testid。真实 MySQL、原生登录与浏览器场景仍由最终同源 CI 验证，组件测试和生产构建不替代该验收。
