## 当前代码边界

`fcp.host` 定义不依赖 Spring/RuoYi 的宿主契约。可信身份必须由宿主鉴权生成，不能从请求体反序列化；TASK 身份不是管理员身份。authorize 每次调用当前策略，旧授权版本不产生永久权限。

`Engine.publishCatalog` 复用既有发布锁、准入和快照，不另外创建执行内核。新目录注册和发布准备失败时恢复 Registry；现有调用持有原快照。该方法仅供可信控制器使用，不是上传即执行 API。数据库意图、文件目录和进程恢复仍由后续协调器负责，不能将内存发布称为全资源事务。

包安装模块负责验证与不可变目录发布，不执行包，不等同于插件已启用。来源白名单和调用者提供的摘要不能冒充密码学签名或恶意代码沙箱。首期仅运行可信代码。
