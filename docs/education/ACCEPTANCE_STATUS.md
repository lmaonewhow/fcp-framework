# 教育基础资料阶段验收状态

本模块基于 dev f362456，针对仓库教育平台 v4.2.1 P042 数据库设计。它不是54表全部业务CRUD交付。当前阶段仅管理端学校/组织/班级受约束新建、名称CAS修改、相关列表/详情与学期只读；不开放删除、身份关系绑定、学期状态转换、评价或积分直接写入。教师端业务页面、现有生产库迁移与授权管理界面不在此阶段。

用户明确的权限规则为租户管理员管理本租户全部学校，学校管理员仅负责学校。角色必须有服务端明确权威映射，并同时满足原生账户、角色、精确菜单、套餐和当前执行许可。创建学校不自动授予代码执行许可，待激活学校只展示等待状态。此限制不改变租户管理员的管理范围。

## 可重复验证入口

`tools/verify_education_contracts.py` 校验54表/548列锁定设计、标量与只读生成策略；`tools/verify_education_foundation.py --java-home "$JAVA_HOME"` 校验纯Java请求及Python计划边界。组件测试、模拟HTTP与SQL协议检查不等于原生验收。

`.github/workflows/native-education.yml` 在一次独立GitHub Actions运行内使用专用loopback MySQL 8.4、Redis 7.4和锁定宿主。`tools/ci_native.py --ingestion --education` 创建新的空库并记录计划及备份，先安装精确宿主，再以独立受限DDL凭证执行锁定P042及教育扩展/菜单。数据库不属于本次创建、非空初始库、源摘要或对象不匹配均停止。没有现有库自动升级入口，不运行生产迁移。

构建执行原生Maven prod标签测试、双前端类型检查和生产构建。教育代码摘要绑定实际JAR；只在既有宿主验收之后添加合成教育角色，运行真实MySQL并发/事务探针、真实原生登录HTTP断言，再对已验证撤销的单一合成权限行进行有记录恢复并重新登录执行浏览器验收。浏览器实际操作组织、班级、CAS冲突、取消、连续点击、刷新、只读界面与新校等待激活，截图不包含登录页、token或真实个人数据。测试代码存在不构成PASS。
