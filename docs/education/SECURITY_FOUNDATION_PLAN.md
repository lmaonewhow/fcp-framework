# 教育安全基础：已落实范围与后续门禁

> 阶段记录：本文保留各子模块首次交付时的本地验证与 NOT_RUN 边界。后续集成的真实运行记录以 [ACCEPTANCE_STATUS.md](ACCEPTANCE_STATUS.md) 和 PR14 的精确提交产物为准；子模块初始状态不是当前集成结论，也不把源码存在当作验收通过。

用户已确认租户管理员管理本租户所有学校、学校管理员只管理自己负责学校。P042的任课关系、自然人账户当前绑定和旧FCP班级权限不包含该管理权，不能拿来冒充新模型。

## 明确的角色权威

新增独立扩展 `ed_host_education_role`，绑定原生 role_id 与明确 TENANT_ADMIN/SCHOOL_ADMIN、学校和固定操作。TENANT_ADMIN使用school_id=0代表当前租户内学校，SCHOOL_ADMIN必须显式school_id。角色名、原生superadmin、浏览器schoolId不构成授权。角色映射默认enabled=0；新增行与启用由可信审批/部署过程执行，不从业务请求缺行时自动生成。精确原生菜单权限、当前用户角色成员关系、原生角色/套餐/用户/租户状态必须同时有效。

生产授权管理页面和首次管理员审批流程尚未提供；隔离CI只创建显式标注的合成角色，不能把fixture SQL用于真实用户库。SQL扩展不加入既有迁移序列；P042与扩展均只在本次新隔离库组合初始化，源摘要与实际对象核对。

## 请求与提交授权

真实LoginHelper提供原始tenant/actor。P042允许100字符tenant，原生宿主当前列宽/账户规则仍受锁定5.6.2限制；不自动扩原生字段，也不在适配器trim/规范化。原生SQL采用BINARY精确比较且返回tenant再与原值String.equals核验，避免PAD SPACE和大小写等价扩大权限。

每次短事务检查并锁定租户/能力栅栏、主体epoch、实际manifest的tenant执行许可，原生用户、租户、角色/成员、菜单/套餐及教育授权映射。学校领域操作还需school执行许可和真实学校归属；角色允许全租户管理不等于任意代码实现可以在每校执行。学校创建不偷偷插入许可，新校目录显示EXECUTION_GRANT_MISSING、操作全关闭，等待可信部署许可。

原生UPDATE/DELETE这些实际授权行会与共享行锁协调。本阶段每次都读取当前权威状态，不接收旧票据或客户端epoch，所以不靠异步权限缓存同步决定提交。精确锁顺序、当前实现和边界见TRANSACTION_IMPLEMENTATION.md。MySQL并发探针是待执行验收代码，源码不等于该锁语义已被证明。

当前并未完成宿主所有管理入口对教育epoch的同步推进；也未提供异步TASK票据与租约。会话logout与已接纳事务的全局排序、任意数据库直接管理写入、恶意DBA绕过不属于已实现保证。未来扩大TASK/跨进程时必须统一权威协调器：原生用户/角色/套餐/菜单/会话变更与对应epoch/栅栏同事务推进，明确撤销确认后拒绝旧任务结果的测试，不得只在controller附一个AOP。

## 已编码的有限领域

只做组织/学校/班级新建、名称CAS修改、学校目录/组织/班级/学期读取、只读操作核对。没有人员身份/关系换绑/状态转换/通用UPDATE/DELETE。CAMPUS/DEPARTMENT父类型组合不由P042定义，因此不新增武断的层级限制；保留同校、有效期和无环校验。班级只能同校DRAFT/OPEN学期，冻结/归档不允许创建，不改学期状态。保留精确uint64字符串、UTC微秒、复合键、业务时态。

事务内当前授权、领域变更、稳定意图账本、COMMITTED审计与outbox一次提交。成功日志失败回滚业务。提交响应丢失/连接异常返回UNKNOWN，不假定回滚；前端先只读查权威账本，查无结果仍UNKNOWN，不能新建意图自动重交。具体命令和恢复契约见FOUNDATION_API.md。

拒绝/失败/UNKNOWN使用独立安全事件连接，当前仅有有界并发与可检测进程内失败计数。持久积压、报警接入与洪泛限速还未完成。当前代码不能声称完整生产安全审计可靠性；增加失败注入与恢复后才能放行更高风险领域。

## 后续必须取得的证据

真实锁定宿主加密登录、精确教育角色和原始tenant校验；两个租户/每租户多学校的越权直调；角色禁用/映射撤销与在途事务双连接排序；新建和名称CAS并发；同意图重复/不同内容与其他主体重放；audit/outbox失败全回滚；真实commit UNKNOWN故障注入；JDBC断线重连UTC与严格SQL检查；浏览器角色变更/未决保存/刷新恢复；重启后的业务和回执持久性。

当前已提供纯Java/Python校验、真实JDBC探针与原生HTTP验收模块。是否通过以同提交同JAR的运行产物为准。MySQL、原生Spring与浏览器在本地无可运行环境时必须写NOT_RUN/BLOCKED，不能把旧FCP验收借给新模块。54表业务、生产迁移/恢复、大规模性能、长期稳定性、Windows与多节点仍不在此阶段交付内。
