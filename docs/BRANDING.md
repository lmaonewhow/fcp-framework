# 智慧云校品牌与默认菜单

此次产品改名覆盖 plus-ui 管理端和 ruoyi-plus-soybean 教师端的网页标题、登录名称、侧栏名称、favicon/logo、默认头像、原生启动横幅，以及发布选择器的中间页标题。移除原首页的上游项目宣传、教师首页的合成统计及动态、顶部项目/文档外链和通知面板的 Gitee 宣传入口。首页只提供已实现业务的入口，不伪造学校指标。原通知、登录验证码、租户、权限、数据库和已实现业务继续使用原生实现。

管理端和教师端均不再预填演示用户名/密码。教师端无条件显示的注册入口现受原注册开关控制。下载代码的文件名和包名示例使用中性学校命名，生成逻辑仍由独立代码生成模块维护。

登录成功后延迟发送的原生 SSE 欢迎语也使用“智慧云校”，后端仅替换该显示字符串，并锁定完整 AuthController 源码前后摘要。两端仍使用原生 SSE、通知面板及认证流程。品牌验收在原登录会话中、显式工作台导航之前等待真实欢迎通知，分别保存 `admin-login-notification.png` 和 `teacher-login-notification.png`；缺少通知或收到旧品牌均失败，不重试登录或伪造事件。普通 CRUD 生成器缺少审计字段时使用中性错误说明，字段要求和拒绝逻辑不变。

原作者许可证和版权完整保留在仓库与发布目录，并复制为双端同源 `third-party-notices.txt`。登录页和页脚的“开源许可”可查看说明。版权文件和技术兼容信息中的 RuoYi/若依不是产品品牌，不作篡改。锁定上游、Maven 坐标、Java 包、JAR 文件名、数据库字段、权限字符串、缓存/会话键、迁移历史及测试夹具保留，避免“全局替换”破坏系统。

V009 仅清理原始 PLUS 官网、测试菜单、测试单表、测试树表及其功能权限项，候选为 14 个固定 seed。锁定工作流中的真实“请假申请”位于原测试目录下，因此完整安装删除 13 项；仅当原始请假子树完整且没有定制时，将保留目录的显示名改为“日常事务”，路径、菜单 ID、权限和引用均不变。所有静态身份字段都必须匹配；改动过的菜单、复用 ID 和自定义子树保留。仅同步清理确定删除菜单的角色和套餐引用，不删角色、账号、部门、测试表或任何业务记录。既有库使用单独审查流程，普通 DDL 迁移器只输出 REVIEW_NATIVE_DATA_ONLY，详见 [迁移说明](MIGRATIONS.md)。

本地验证包含锁定三仓组装、品牌补丁完整性与漂移拒绝、菜单 SQL 语义回归、安装 ledger 以及 Java 迁移包检查。SQLite SQL 适配测试不能代替 MySQL 8，Java 21 默认目标编译不能代替 Java 17 目标检查。完整原生流水线包含真实 MySQL、双端类型检查/生产构建、原生加密登录及品牌/服务端菜单验收，截图与结果写入该次运行的 `reports/native-branding/`。结果须绑定实际提交及构建，源码与流程定义本身不是通过证据。不得据此宣称生产发布、用户电脑部署或长期稳定性已完成。
